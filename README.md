# Tic-Tac-Toe (איקס-עיגול)

A simple two-player Tic-Tac-Toe game that runs in the terminal. The game interface is in Hebrew.

## Requirements

- Python 3.x

## How to run

```bash
python tictactoe.py
```

## How to play

1. Player **X** starts.
2. On your turn, enter a **row** and **column** separated by a space (for example: `1 2`).
3. Rows and columns are numbered `1`–`3`.
4. The first player to get three in a row (horizontally, vertically, or diagonally) wins.
5. If the board fills with no winner, the game ends in a draw.
6. After each game, you can choose to play again (`כ` / `כן` / `y` / `yes`).
